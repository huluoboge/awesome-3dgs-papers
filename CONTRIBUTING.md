# Contributing

Thanks for helping maintain this 3DGS paper index.

For each addition or correction, include:
- Paper title and arXiv ID (or the publisher's stable paper URL)
- Publication venue and year, or a clear preprint status
- One primary category and any relevant cross-cutting categories
- A concise contribution note
- The authors' official code repository, when available
- The date paper and code links were last checked

Please avoid duplicates, distinguish official code from third-party implementations, and keep `README.md` and `papers.csv` in sync.
